# PIECS Library MVP

## Product scope
- Dark Studio interface, responsive React SPA.
- Browse and filter starter templates by category/profile/search.
- View template details, copy slash-command prompt and JSON.
- Save favorites in current app state (persistence is a follow-up task).
- Browse all 80 commands grouped into eight PIECS modules.

## Explicit MVP limitations
- Template thumbnails are abstract placeholders, not real before/after examples.
- No authentication, database, cloud sync, image upload, AI execution, or template publishing yet.
- New template button is a visual placeholder pending the Template Builder story.

## Run locally
```bash
npm install
npm run dev
npm run build
```
